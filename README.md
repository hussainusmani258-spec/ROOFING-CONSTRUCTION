### 1. 🚀 About The Project

Yeh project ek modern aur responsive **Saloon & Beauty Care Website** ka landing page hai. Isme clients ke liye clean user experience, beauty services, pricing, aur interactive appointment booking section tayar kiya gaya hai.

- 🌐 **Live Demo:** [Click Here to View Live Website](https://axyz79154-maker.github.io/Saloon/index.html)

---

### 2. ✨ Key Features

- 📱 **Fully Responsive Layout:** Mobile, Tablet, aur Desktop devices ke liye optimized.
- 💈 **Service Catalog:** Haircuts, Styling, Facial, Spa, aur Grooming services ka visual grid showcase.
- 📅 **Interactive Appointment Form:** Easy-to-use booking UI.
- 🎨 **Modern Aesthetics:** Clean typography, smooth transitions, aur attractive color palettes.
- ⚡ **Fast Performance:** Pure HTML, CSS, aur lightweight JavaScript logic.

### 5. ⚡ Quick Setup & Installation

Project ko local machine par run karne ke liye yeh steps follow karein:

1. **Repository Clone Karein:**
   ```bash
   git clone [https://github.com/axyz79154-maker/Saloon.git](https://github.com/axyz79154-maker/Saloon.git)
   ```

2. **Project Folder Open Karein:**
   ```bash
   cd Saloon
   ```

3. **Open in Browser:**
   Directly `index.html` file ko double click karein ya Live Server extension se VS Code mein run karein.
